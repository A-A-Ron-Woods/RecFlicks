# RecFlicks - Movie Recommendation App

RecFlicks is a **movie recommendation system** that helps users discover movies based on **genre & release year** or find **similar movies** to their favorites using Machine Learning.

## Features
- **Recommend Movies by Genre & Year Range**
- **AI-Based Similar Movie Suggestions**
- **Fetch Movie Posters & Overviews from TMDB API**
- **User-Friendly UI with Streamlit**

## Installation
1. Clone the repo:
git clone https://github.com/A-A-Ron-Woods/RecFlicks.git cd RecFlicks

2. Install dependencies:
pip install -r requirements.txt

3. Run the app:
python run_app.py

4. Open `http://localhost:8501` in your browser (if it doesn't open automatically).
